1. PURPOSE & HIGH-LEVEL OVERVIEW

HESPERIA is a deterministic semantic substrate designed to stabilize meaning, structure retrieval,
govern reasoning, and provide explicit metrics that LLMs alone cannot maintain.
It combines:
- a fixed geometric lattice (12 Areas × 288 Families),
- attribution engine (words → sentences → statements → sphere),
- 6-axis polarity model,
- structural truth geometry,
- obstacle and safety models,
- ingestion, retrieval, and loop-based semantic traversal.

3. GEOMETRY & STRUCTURAL MECHANICS

The HESPERIA geometry is deterministic:
- Each truth unit resides on a side.
- Each side belongs to a hex.
- 250 hexes form one Family.
- 24 Families form one Area.
- Areas exist on a closed semantic ring.

Key metrics:
T(R) — truth magnitude.
C(R) — coherence (largest cluster / active sides).
X_A(R) — Area alignment.
X_F(R) — Family alignment.
fragIndex(R) — fragmentation.
tensionEnergy — polarization across 6 axes.
ringSmoothness — spectral coherence measure.
coveragePhi — semantic coverage in loop traversal.

 
4. ATTRIBUTION ENGINE (WORD → SENTENCE → STATEMENT)

Word-level:
1. Dictionary match
2. Nearest-neighbor voting
3. Family centroid similarity
4. Axis polarity correction
5. Phrase/sentence overrides

Sentence-level:
- Aggregate word families and areas
- Softmax normalization
- Dominant family/area selection

Statement-level:
- Aggregate sentences
- Embedding-based centroid correction
- Final Area/Family assignment
- Compute inward/outward vectors

 
5. SIX-AXIS POLARITY MODEL

Axes define antagonistic semantic forces:
0: GOOD / HARM
1: TRUTH / DECEIT
2: ORDER / CHAOS
3: FREEDOM / CONTROL
4: CARE / INDIFFERENCE
5: CREATION / DESTRUCTION

Polarity:
    b_k = dot(normalize(E), axisDir[k])

Used for:
- Family correction
- Area validation
- Drift detection
- Safety boundaries

 
6. FORWARD EVOLUTION (USER INPUT → HESPERIA GEOMETRY)

1. Tokenize text
2. Classify words with 5-stage execution_flow
3. Build SentenceAttributions
4. Build StatementAttribution
5. Compute inward/outward semantics
6. Place statement into Sphere geometry
7. Retrieve region
8. Run loop traversal

 
7. BACKWARD EVOLUTION (SPHERE → DICTIONARY REFINEMENT)

Dictionary can only change via backward():
- Compare word family vs statement family
- If inwardAllowed: update dictionary
- Else: record outward reference

Ensures controlled, auditable evolution.

 
8. LOOP TRAVERSAL & SEMANTIC DYNAMICS

Traversal:
- Start at dominant Area
- Move clockwise along AREA_RING_ORDER
- Score families
- Apply obstacle gating
- Stop on convergence or obstacle

Metrics:
- loopability
- coveragePhi
- obstacle windows
- tensionEnergy
