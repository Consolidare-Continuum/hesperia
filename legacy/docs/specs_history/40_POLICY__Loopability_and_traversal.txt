## 1. Overview

This document consolidates the full discussion on loopability, ring traversal, fixed geometry rules, novelty detection, and multi-pass traversal logic for the Sphere semantic engine. All formulas are expressed in a Java-friendly mathematical notation. The conceptual structure is frozen: the ring of Areas is fixed, the Families within Areas are fixed, and only per-statement activations vary.

The goal is to formalize:

* Ring-based semantic traversal.
* Multi-pass loopability reasoning (up to 3 passes).
* Novelty discovery (families + statements).
* Axis evolution.
* Stop conditions.
* Equal-direction opportunity.

This becomes the policy and the deterministic mathematical skeleton of loopability.

## 2. Fixed Geometry

### 2.1 Areas

```java
final int AREA_COUNT = 12;
Area A[12]; // Fixed clockwise geometry
```

Adjacency:

```java
int left(int i)  { return (i - 1 + AREA_COUNT) % AREA_COUNT; }
int right(int i) { return (i + 1) % AREA_COUNT; }
```

### 2.2 Families

```java
class Family {
    int id;
    int area; // fixed mapping 0..11
}
```

Families never change area or position.

### 2.3 Statement Activations

```java
Map<Family, Double> d_f; // base activation d_f(s) >= 0
```

Area aggregation:

```java
double alpha[i] = sum(d_f over families with family.area == i);
double sumAlpha = sum(alpha);
double A_vec[i] = alpha[i] / sumAlpha;
```

## 4. Ring Traversal: Passes and Steps

### 4.1 Pass Control

We allow up to 3 passes:

```java
final int MAX_PASSES = 3;
final int STEPS_PER_PASS = AREA_COUNT; // one full ring
```

### 4.2 Direction Logic

```java
int directionForPass(int p, int noveltyP1, int noveltyP2) {
    if (p == 1) return +1; // clockwise
    if (p == 2) return -1; // counterclockwise
    // pass 3 chooses more productive direction
    return (noveltyP1 >= noveltyP2) ? +1 : -1;
}
```

### 4.3 Step Area Index

```java
int areaAt(int start, int direction, int step) {
    return (start + direction * step + AREA_COUNT) % AREA_COUNT;
}
```

## 9. Pass Execution Logic

```java
int startArea = argMax(A_vec); // starting point from activation
for (int p = 1; p <= MAX_PASSES; p++) {

    int direction = directionForPass(p, G_F[1] + G_S[1], G_F[2] + G_S[2]);

    for (int t = 0; t < STEPS_PER_PASS; t++) {
        int currentArea = areaAt(startArea, direction, t);

        // store previous cumulative
        Map<Family, Double> oldC = clone(C_f);

        // update cumulative activation
        for (Family f : FAMILIES) {
            double g = (f.area == currentArea) ? d_f.get(f) : 0.0;
            C_f.put(f, oldC.get(f) + g);
        }

        // detect new families
        List<Family> newF = detectNewFamilies(oldC, C_f);
        G_F[p] += newF.size();

        // detect new statements
        List<String> newS = detectNewStatements(currentArea);
        G_S[p] += newS.size();
    }

    // stopping
    double fNorm = G_F[p] / (double) STEPS_PER_PASS;
    double sNorm = G_S[p] / (double) STEPS_PER_PASS;
    if (fNorm < EPS_F && sNorm < EPS_S) break;
}
```

## 10. Loopability Core Meaning

Loopability is the system’s measure of how much **new semantic territory** is unlocked while traversing the fixed semantic ring.

Principles:

1. Ring is fixed — traversal order never changes.
2. Families are fixed — no runtime drift.
3. Only activations change.
4. Loopability measures *novelty per hop*, not movement.
5. Multiple passes allow equal opportunity for both directions.
6. Early stopping prevents useless extra cycles.
7. Novelty = threshold-crossing (families) + unseen contextual statements.

Summary: deterministic, interpretable, reproducible multi-pass semantic exploration.

---

## 11. Full-Pass Loopability Metric

For a single pass:

```java
double L_full = (double) G_F[p] / STEPS_PER_PASS;
```

Optionally weighted with statements:

```java
double L_weighted = (G_F[p] + lambda * G_S[p]) / STEPS_PER_PASS;
```

Where `lambda` balances family vs. statement novelty.

## 12. Axis Evolution Over Passes

After each step, compute updated area vector:

```java
double alpha_t[i] = sum(C_f over families f where f.area == i);
double sumAlphaT = sum(alpha_t);
double A_vec_t[i] = alpha_t[i] / sumAlphaT;
AxisVector B_t = computeAxes(A_vec_t);
```

The sequence `{B_t}` is the diagnostic trace of semantic polarity over the ring traversal.
