============================================================
HESPERIA — SPEC v0.3.3
Deterministic Attribution & Region Seeding
============================================================

Status: Additive (non-breaking vs v0.3.2)
Depends on: v0.3.2 implementation (Σ enforced, 6-key contract frozen)

0. PURPOSE

v0.3.3 wires real semantic raw_text into the engine:
- Deterministic Attribution Layer
- Region Seed Construction
- Full Steps 0–2 execution_flow compliance
- Optional Shadow activation in HTTP path (config-controlled)
No stochastic learning. No probabilistic LLM weighting. Dictionary-based only.

1. PIPELINE

POST /hesperia/analyze executes:
Step 0 — Normalize: NFKC, lowercase, whitespace collapse, hard cap (default 10_000). Reject > cap → 413.
Step 1 — Tokenize: Whitespace split, strip punctuation. No stemming.
Step 2 — Attribution: Dict A exact → (familyGlobal, altitude); else Dict B → familyGlobal; else ignore.
Aggregation: dominant family = argmax(hits_F); tie-break lowest meanAltitude then lowest familyGlobal.
Dominant area = floor(dominant_family / 24).
Step 3 — Region seed: tau(side) = base_weight * hitDensity_F * (1 - meanAltitude_F) for sides in F.
Step 4 — Traversal → Guards → (optional shadow) → minimal 6-key summary.

2. DICTIONARIES

Dictionary A: lemma → { familyGlobal: int, altitude: float ∈ [0,1] }. Versioned files; no runtime modification.
Dictionary B: token → sideId or familyGlobal. Pre-frozen.
familyGlobal ∈ [0,287]. sideId ∈ [0,431_999]. Violation → Sigma failure.

3. FAILURE CONDITIONS

text missing → 400
length cap → 413
no tokens matched (semantic vacuum) → 400
any metric NaN/Inf → 500

4. NEW METRICS (extended summary only, not in minimal contract)

total_tokens, matched_tokens, unmatched_tokens, attribution_coverage, meanAltitude_global.

5. IMPLEMENTATION

sphere_rag/analyze_v033.py — analyze_v033(text, ...) → (minimal_6key, extended).
sphere_rag/serve_v033.py — v0.3.3: uses analyze_v033; 400/413/500; version 0.3.3 (filename matches version).
