12.1 DATA SCHEMAS (SQL)

table dictionary_word { lemma, family_id, area_id, embedding }

////////////////////////////////////////////////////////////
12.2 VECTOR DATABASE COLLECTIONS
////////////////////////////////////////////////////////////
// Purpose: semantic search + sharded retrieval.

collection words       { lemma, family_id, area_id, embedding }
collection statements  { statement_id, family_id, area_id, embedding }
collection families    { centroid }
collection areas       { centroid }


////////////////////////////////////////////////////////////
12.3 PIPELINE: INGESTION (BUILD PHASE)
////////////////////////////////////////////////////////////
// Purpose: convert raw corpus into fully attributed HESPERIA structure.

processBook(file):
    - split text into statements (3–5 sentences)
    - SA = forward(statement)
    - store in SQL (statement table)
    - embed text for retrieval
    - insert embedding → vector DB
    - assignSide(statement_id) into hex/side geometry
    - update tau on side


////////////////////////////////////////////////////////////
12.4 PIPELINE: QUERY (RUNTIME)
////////////////////////////////////////////////////////////
// Purpose: classify user query → locate in HESPERIA → retrieve region.

queryPipeline(text):
    SA = forward(text)
    region = searchShard(SA.family, SA.area)
    hops = runLoop(region)
    metrics = computeStructureMetrics(region)
    return buildAnswer(SA, region, metrics)


////////////////////////////////////////////////////////////
12.5 PIPELINE: RETRIEVAL (SHARDING)
////////////////////////////////////////////////////////////
// Purpose: improve semantic relevance by restricting search space.

searchShard(family, area):
    - search vector DB for nearest statements
      filtered by {family_id, area_id}
    - return top-K for region construction


////////////////////////////////////////////////////////////
12.6 PIPELINE: REGION CONSTRUCTION
////////////////////////////////////////////////////////////
// Purpose: transform retrieved statements → lattice region R.

buildRegion(statementHits):
    - locate sides for each statement
    - union sides into Region R
    - compute structural metrics (T, C, X_A, etc.)


////////////////////////////////////////////////////////////
12.7 PIPELINE: LOOP-BASED REASONING
////////////////////////////////////////////////////////////
// Purpose: run semantic loop for controlled inference.

runLoop(R):
    - start area = argmax(A_vec)
    - hop around ring sequence
    - accumulate Families
    - stop on obstacle or convergence


////////////////////////////////////////////////////////////
12.8 PIPELINE: SEMANTIC ANSWER GENERATION
////////////////////////////////////////////////////////////
// Purpose: produce structured semantic output.

buildAnswer(SA, region, metrics):
    - include top families, areas
    - include inward/outward tendencies
    - include structural metrics
    - optionally provide explanation text

14. HUMAN-READABLE PIPELINE SUMMARY (ADDED IN v4.5)
============================================================

1. **User input arrives**
   - Text is split, embedded, and classified.

2. **Word attribution**
   - Dictionary → NN search → centroid → polarity.

3. **Sentence attribution**
   - Word families aggregated into 288–D + 12–D distributions.

4. **Statement attribution**
   - Sentence distributions merged, embeddings applied.
   - Assigns statement’s Family + Area.
   - Computes inward/outward cross-Area tendencies.

5. **Placement into HESPERIA Geometry**
   - Statement occupies one side (atomic truth slot).
   - tau updated.

6. **Region retrieval**
   - Query retrieves statements from same family/area shard.

7. **Region construction**
   - Sides of retrieved statements merged into a Region R.

8. **Semantic loop traversal**
   - Ring-based movement explores related Areas.
   - Halts on obstacles or convergence.

9. **Structured output**
   - Includes region summary, metrics, dominant families/areas,
     inward/outward semantics, loop results.

10. **Optional backward correction**
   - Dictionary updated only if inward semantics allow.
