# Runtime example configs

JSON examples for **semantic field** and **HCI field calibration** pipelines.

| File | Command |
|------|---------|
| `semantic_field_example.json` | `python3 -m runtime.semantic_field.run_semantic_field --config runtime/configs/…` |
| `semantic_field_ontology_example.json` | Same; ontology-derived matrices |
| `field_calibration_example.json` | `python3 -m runtime.semantic_field.run_field_calibration --config …` |

Paths in docs may use `runtime/configs/<file>.json` from repo root.
