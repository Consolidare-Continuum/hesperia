# TRIZ demo (examples)

Deterministic demo reports built from small benchmark corpora.

```bash
python3 examples/extensions/triz_demo/triz/make_demo_reports.py
```

Outputs default to `examples/extensions/triz_demo/triz/outputs/` (small committed samples). For large local reruns, prefer `outputs/reports/` per **`GENERATED_ARTIFACT_POLICY.md`**.
