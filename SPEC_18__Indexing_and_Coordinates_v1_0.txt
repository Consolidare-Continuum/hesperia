HESPERIA — INDEXING & COORDINATE SPEC v1.0

1. GEOMETRY CONSTANTS

AREAS = 12 FAMILIES_PER_AREA = 24 HEXES_PER_FAMILY = 250 SIDES_PER_HEX =
6

TOTAL_FAMILIES = 288 TOTAL_HEXES = 72,000 TOTAL_SIDES = 432,000

SIDES_PER_FAMILY = 1,500 SIDES_PER_AREA = 36,000

2. CANONICAL 4D COORDINATE

Each atomic truth unit is one side of a hex.

Zero-based coordinates:

area ∈ [0..11] familyLocal ∈ [0..23] hexIndex ∈ [0..249] sideIndex ∈
[0..5]

Global family index:

familyGlobal = area * FAMILIES_PER_AREA + familyLocal

3. LINEAR SIDE INDEX (sideId)

sideId ∈ [0..431,999]

Forward mapping:

familyGlobal = area * FAMILIES_PER_AREA + familyLocal

sideId = (((familyGlobal * HEXES_PER_FAMILY) + hexIndex) *
SIDES_PER_HEX) + sideIndex

Ordering: familyGlobal → hexIndex → sideIndex

Implications: - Family block size = 1,500 sides - Area block size =
36,000 sides - Full sphere = 432,000 sides

Inverse mapping:

sideIndex = sideId % SIDES_PER_HEX tmp = sideId / SIDES_PER_HEX

hexIndex = tmp % HEXES_PER_FAMILY familyGlobal = tmp / HEXES_PER_FAMILY

area = familyGlobal / FAMILIES_PER_AREA familyLocal = familyGlobal %
FAMILIES_PER_AREA

Identity rule: coord → sideId → coord = exact match

4. HUMAN-READABLE LABEL

Format: Aaa-Fff-Hhhh-Ss

Example:

Internal: area = 2 familyLocal = 4 hexIndex = 119 sideIndex = 3

Human label: A03-F05-H120-S3

5. OPTIONAL 32-BIT PACKED CODE

Bit allocation: area : 4 bits familyLocal : 5 bits hexIndex : 8 bits
sideIndex : 3 bits

Encoding:

encodeSide(area, familyLocal, hexIndex, sideIndex): (area << 16) |
(familyLocal << 11) | (hexIndex << 3) | (sideIndex)

Decoding:

decodeSideIndex(code) = code & 0b111 decodeHexIndex(code) = (code >> 3)
& 0xFF decodeFamilyLocal(code) = (code >> 11) & 0x1F decodeArea(code) =
(code >> 16) & 0x0F

Packed code is transport-only. Canonical storage remains (area,
familyLocal, hexIndex, sideIndex) or sideId.

6. JAVA REFERENCE STRUCTURE

class SideCoord {

    int area;
    int familyLocal;
    int hexIndex;
    int sideIndex;

    int familyGlobal() {
        return area * FAMILIES_PER_AREA + familyLocal;
    }

    int sideId() {
        int fam = familyGlobal();
        return ((fam * HEXES_PER_FAMILY) + hexIndex)
               * SIDES_PER_HEX + sideIndex;
    }

    static SideCoord fromSideId(int sideId) {

        int sideIndex = sideId % SIDES_PER_HEX;
        int tmp       = sideId / SIDES_PER_HEX;

        int hexIndex     = tmp % HEXES_PER_FAMILY;
        int familyGlobal = tmp / HEXES_PER_FAMILY;

        int area        = familyGlobal / FAMILIES_PER_AREA;
        int familyLocal = familyGlobal % FAMILIES_PER_AREA;

        return new SideCoord(area, familyLocal,
                             hexIndex, sideIndex);
    }

}
