0. PRINCIPLES
------------------------------------------------------------

P0. Canonical geometry remains authoritative.

P5. Agreement tracking is strictly one-step ahead.
P6. Local decision space per step is exactly 6 candidates.

============================================================
1. INPUT CONTRACT (EXTENDED RUN LOG)
------------------------------------------------------------

For each traversal run r:

struct RunLog {
    long runId;
    long timestamp;

    int dominantArea;
    int dominantFamily;

    double C_R;
    double X_A_R;
    double X_F_R;
    double fragIndex_R;
    double areaEntropy_R;
    double tensionEnergy_R;

    Map<Integer, Double> familyMass;
    // familyMass[f] = Σ tau[s] for sides in Region R

    double SDA_run;
    double Agreement_rate;
    double Mean_rank;
}

============================================================
2. SHADOW GRAPH STRUCTURE
------------------------------------------------------------

Nodes:
    Families (0..287)

Matrices:
    double W[288][288];       // directed weighted
    double W_norm[288][288];  // row-normalized

Initialization:
    W[f][g] = 0 for all f,g

============================================================
3. CHANNEL A — CO-PRESENCE UPDATE
------------------------------------------------------------

For each run r:

Let F_r = families where familyMass[f] > 0.

For all ordered pairs (f,g), f != g:

    m_f = familyMass[f]
    m_g = familyMass[g]

    quality =
        C_R
      * X_A_R
      * (1.0 - fragIndex_R)

    delta =
        m_f * m_g * quality

    W[f][g] += delta

Interpretation:
    Coherent, low-fragmentation regions
    strengthen relational weight.

============================================================
4. CHANNEL B — OUTWARD REFERENCE UPDATE
------------------------------------------------------------

For each family f in region:

For each area A where outwardVector[A] > 0:

    Identify families g in region
    where areaOf(g) == A

    For each such g:

        delta =
            outwardVector[A]
          * familyMass[g]
          * C_R

        W[f][g] += delta

Interpretation:
    Cross-area influence only counted
    if supported by actual retrieval presence.

============================================================
5. NORMALIZATION
------------------------------------------------------------

For each family f:

    total = Σ_k W[f][k]

    if total > 0:
        W_norm[f][g] = W[f][g] / total
    else:
        W_norm[f][g] = 0

============================================================
6. CHANNEL C — STEP-LEVEL AGREEMENT INSTRUMENT
------------------------------------------------------------

At traversal step t:

    int f_t             // current family
    List<int> candidates = {g1..g6}
    |candidates| = 6

Shadow local scoring:

    score[g] = W_norm[f_t][g]
    (only for g in candidates)

Prediction:

    f_shadow = argmax(score[g])

If all scores == 0:
    mark step as NoShadowSignal

------------------------------------------------------------

Step-level metrics:

Weighted:

    SDA_weighted_t = score[f_real]

Binary:

    SDA_binary_t =
        1 if f_real == f_shadow
        0 otherwise

Rank:

    Rank_real_t =
        position of f_real
        in sorted(score[g])

Range: 1..6

------------------------------------------------------------

Run-level aggregates:

For T valid steps:

    SDA_run =
        (1/T) * Σ SDA_weighted_t

    Agreement_rate =
        (1/T) * Σ SDA_binary_t

    Mean_rank =
        (1/T) * Σ Rank_real_t

============================================================
7. FAMILY STRUCTURAL METRICS
------------------------------------------------------------

For each family f:

    deg_out = Σ_g W[f][g]
    deg_in  = Σ_g W[g][f]
    deg = deg_out + deg_in

    p_g = W[f][g] / deg_out

    H_out(f) =
        - Σ p_g * log(p_g)

    ShadowRichness(f) =
        log(1 + deg)
        * H_out(f)
        * Stability(f)

Stability(f):
    cosine similarity between
    normalized W vectors across windows.

============================================================
8. DIVERGENCE CLASSIFICATION
------------------------------------------------------------

If:
    C_R high
    AND SDA_run low
→ Structural Divergence

If:
    fragIndex_R high
    AND SDA_run low
→ Noise Divergence

If:
    SDA_run high
    AND Stability rising
→ Convergence
