# Dict-B — граф концептов (LEVEL 3)

**Язык:** русский. Все пользовательские значения (определения, примеры контекста, метки), 
ввод-вывод и операционные наименования — на русском. Литература и источники — на русском.

## Назначение

Семантический граф концептов для TFP/Кернберг: **ОБЛАСТИ → СЕМЬИ → КОНЦЕПТЫ**.
Текст сессии → лексические маркеры → концепты → активация семьи → активация области.

## Файлы

| Файл | Описание |
|------|----------|
| `dictB_schema.yaml` | Схема узла и связей; описания на русском. |
| `concept_nodes.yaml` | Узлы-концепты: id, label (транслит), definition, example_context — на русском. |
| `concept_relations.yaml` | Связи между концептами (source, relation, target). |

## Наблюдаемость

`clinical_observability`: **высокий** | **умеренный** | **латентный**.

## Пилот

Пилотные области: A2 (Объектные отношения), A3 (Защитные операции), A4 (Агрессия), A10 (Процесс лечения).
~120 узлов. Остальные области дополняются по тому же шаблону.
