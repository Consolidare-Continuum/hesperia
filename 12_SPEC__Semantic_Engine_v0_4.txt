===========================================================
0. Global Dictionary & Embedding Structures
===========================================================

Purpose:
Provide deterministic lexical grounding for Sphere semantic geometry.
Words must map into 288 Families and 12 Areas without runtime LLM drift.

Components:
- Primary lexical dictionary: lemma → familyId
- familyToArea: mapping family → area
- embedWord: embedding vectors for words
- embedFamily: 288 family centroids
- embedArea: 12 area centroids
- axisPos/axisNeg: 6 bipolar semantic axes (positive & negative poles)

Thresholds:
- THRESH_DICT: dictionary priority
- THRESH_NN: nearest-neighbor similarity
- THRESH_FAM: family centroid similarity
- THRESH_AXIS: polarity alignment threshold


===========================================================
1. WORD ATTRIBUTION PIPELINE (5-STAGE)
===========================================================

Goal:
Stably map any English word into a Family and Area.

Hierarchy:
1. Dictionary match (strongest, deterministic)
2. Nearest-word vector DB match (similar known words)
3. Family centroid similarity (288 gravity wells)
4. Axis polarity correction (GOOD/HARM, TRUTH/DECEIT, etc.)
5. Phrase & sentence overrides


-----------------------------------------------------------
1.1 Dictionary Match
-----------------------------------------------------------
If the word exists in the curated dictionary:
    family = dict[word]
Return immediately.

This constitutes 60–70% of all classifications.


-----------------------------------------------------------
1.2 Nearest-Neighbor Word Matching
-----------------------------------------------------------
- Embed the word Ew.
- Query vector DB for top-K nearest known words.
- For neighbors with similarity ≥ THRESH_NN:
      count families of each neighbor word
- The densest family becomes the classification.


-----------------------------------------------------------
1.3 Family Centroid Similarity
-----------------------------------------------------------
If nearest neighbors are ambiguous:
- Compute cosine(Ew, embedFamily[f]) for all 288.
- Pick the highest.

This uses family semantic centroids to pull unknown words.


-----------------------------------------------------------
1.4 Bipolar Axis Polarity Correction
-----------------------------------------------------------
Each word is projected onto:
GOOD/HARM,
TRUTH/DECEIT,
ORDER/CHAOS,
FREEDOM/CONTROL,
CARE/INDIFFERENCE,
CREATION/DESTRUCTION.

axisScore[k] = cos(Ew, axisPos[k]) – cos(Ew, axisNeg[k])

If polarity contradicts the family’s Area:
→ flip to the opposite Area’s nearest Family.


-----------------------------------------------------------
1.5 Phrase & Sentence Overrides
-----------------------------------------------------------
After context is analyzed:
- If a word’s family conflicts with sentence meaning:
    If outwardAllowed(wordFamily → sentenceArea):
        override to sentence family
    Else mark as outward reference (not override).

This prevents lexical misfires ("kill the lights", "burnout", etc.).


===========================================================
2. SENTENCE ATTRIBUTION PIPELINE
===========================================================

Input:
Tokenized words with assigned families/areas.

Process:
- Aggregate family frequencies across words.
- Aggregate area frequencies.
- Normalize to probability vectors F_sentence and A_sentence.
- Apply overrides based on centroid(E_sentence).

Output:
- dominantFamily
- dominantArea
- family distribution
- area distribution


===========================================================
3. STATEMENT ATTRIBUTION PIPELINE
===========================================================

A Sphere statement = 3–5 sentences.

Process:
1. Aggregate F_sentence vectors → F_statement
2. Aggregate A_sentence vectors → A_statement
3. Embed full statement (E_statement)
4. Combine:
    - Sentence-level aggregation
    - Family centroid similarity
    - Axis polarity alignment
5. Choose:
    - Statement Area
    - Statement Family
6. Compute inward/outward vectors:
    inward[A] = familyInward[f][A]  * cos(E_statement, embedArea[A])
    outward[A] = familyOutward[f][A] * cos(E_statement, embedArea[A])

Output:
StatementAttribution object:
- F_statement
- A_statement
- family
- area
- inwardVector
- outwardVector


===========================================================
4. INWARD/OUTWARD SEMANTIC DYNAMICS
===========================================================

familyInward[f][A]: how much Family f strengthens Area A
familyOutward[f][A]: how much Family f legitimately references Area A

Used to:
- detect cross-Area references
- detect overreach
- regulate semantic boundaries
- compute hitAndRun dynamics


===========================================================
5. EVOLUTION PIPELINE (FORWARD & BACKWARD)
===========================================================

Purpose:
Provide reversible semantic flow:
word → sentence → statement → sphere
and back:
sphere → statement → lexical corrections.


-----------------------------------------------------------
5.1 Forward Evolution (User Input → Sphere Region)
-----------------------------------------------------------

Steps:
1. Tokenize incoming text
2. Classify each word (5-stage pipeline)
3. Build sentence attributions
4. Build statement attribution
5. Compute inward/outward vectors
6. Locate statement in Sphere (Family & Area)
7. Retrieve nearest Sphere statements (optional)
8. Construct region and run Sphere loop traversal


-----------------------------------------------------------
5.2 Backward Evolution (Statement → Dictionary Correction)
-----------------------------------------------------------

For each word in the statement:
- fam_word = classifyWord(word)
- fam_stmt = statementFamily
If fam_word != fam_stmt:
    If inwardAllowed(fam_word → fam_stmt):
         dict[word] = fam_stmt
    Else:
         record outward reference (word depends on external Area)

This maintains dictionary purity and learns outward vocab.


===========================================================
6. DATA STRUCTURES
===========================================================

Word-Level:
- dictWordToFamily : Map<String,Integer>
- embedWord        : Map<String,double[]>
- embedFamily      : double[288][D]
- embedArea        : double[12][D]
- axisPos/axisNeg  : double[6][D]

Sentence-Level:
class SentenceAttribution {
    double[] F_sentence;   // 288
    double[] A_sentence;   // 12
    int dominantFamily;
    int dominantArea;
}

Statement-Level:
class StatementAttribution {
    double[] F_statement;  // 288
    double[] A_statement;  // 12
    int family;
    int area;
    double[] inwardVector;  // 12
    double[] outwardVector; // 12
}

Evolution Engine:
class EvolutionPipeline {
    StatementAttribution forward(String statementText);
    void backward(StatementAttribution St, String statementText);
}


===========================================================
7. GENERAL MODEL DESCRIPTION (SUMMARY)
===========================================================

1. Words classified using a deterministic 5-layer system.
2. Sentences formed by aggregating word distributions.
3. Statements formed by aggregating 3–5 sentences, with centroid correction.
4. Inward/outward vectors computed per statement using family matrices.
5. Forward evolution places user text into Sphere geometry.
6. Backward evolution refines dictionary and outward reference maps.
7. The system is fully deterministic, auditable, and reversible.
