## 2. Allowed: brain → dev (link manifest only)

- Brain publishes a **path manifest** into dev: `docs/brain-links/MANIFEST.md` (generated by `scripts/hesperia-sync-brain-links-to-dev.sh`).
- Manifest lists **where** team/process lives in brain (operational/, cluster/, governance/) — **not** a copy of brain tree into dev git.
- Optional **disk-only** mirror (off git): `/data/hesperia/cursor-brain-mirror/` via `tools/mirror_cursor_brain_into_hesperia_data.sh` on Hesperia host — **never** commit mirror into `igareosh/hesperia` or brain.

---

## 3. Forbidden

| Action | Why |
|--------|-----|
| **Destructive top ingest** of `igareosh/hesperia` (or prod tree) **into brain repo root** | Brain is not a product clone; pollutes cursor/git |
| `git remote add` hesperia on brain | [ETHAN-POLICY-HESPERIA-PUSH-AND-REMOTES.md](ETHAN-POLICY-HESPERIA-PUSH-AND-REMOTES.md) |
| `rsync --delete` dev → brain | Same |
| Copy `hesperia/`, `output_views/`, `assets/calibration/` into brain | Product code belongs in Hesperia repos only |
| Full `CLIENTS/hesperia` spec tree mirror into brain without selective policy | Brain keeps **INDEX + pointers**; canonical specs live on **dev** after HES-SPLIT |
