HESPERIA — Canonical Families v1.0

Glossary references (see `ACADEMIC.md`):
- Areas and Families: lines 60–90
- Geometry context (hexes, sides, regions): lines 92–106

This file defines a cleaned, non-overlapping, neutral set of 24 Families per Area,
plus designated edge-families that drive transitions between neighboring Areas on the ring.

Ring order (clockwise): GOOD → CARE → ORDER → CONTROL → INDIFFERENCE → HARM → DESTRUCTION → CHAOS → FREEDOM → TRUTH → CREATION → GOOD

DECEIT is the antipode of TRUTH and is treated as sitting radially opposite TRUTH,
with border behavior defined toward CONTROL (regulatory use of deception) and TRUTH (epistemic tension).

For each Area:
  - Families: 24 canonical family labels.
  - Edges_to_prev_area: Families that conceptually border the previous Area on the ring.
  - Edges_to_next_area: Families that conceptually border the next Area on the ring.
