------------------------------------------------------------
How to build
------------------------------------------------------------

From CLIENTS/hesperia (repo root for Hesperia):

1. **Python env**: Python 3.9+. For v0.4.0/v0.4.1 lexical builds: `pip install -r requirements_v040.txt` (or use .venv_v040). Model downloaded on first run.

2. **v0.4.0 build** (Dict A → anchors → Dict B → surface):
   python -m sphere_rag.build_v040 --assets-root hesperia_lex/curated --out-dir assets/v040 --allow-small-build

3. **v0.4.1 Dict B** (needs v0.4.0 artifacts):
   python -m sphere_rag.build_v041 --assets-root assets --out-dir assets/v041 --allow-small-build

4. **Layer stack**: No separate build. Layers are Python modules in sphere_rag/layers/; use load_defaults() and run_l1_through_l9 for full pass.

5. **Pre-test** (optional): python scripts/run_hesperia_pre_test.py or python sphere_rag/run_simulation.py pretest

------------------------------------------------------------
How to use
------------------------------------------------------------

- **Full L1–L9 pass** (canonical): From CLIENTS/hesperia, ensure docs/layer_runs exists (mkdir -p docs/layer_runs), then:
  python3 -m sphere_rag.layers.run_l1_through_l9 --out docs/layer_runs/latest_L1_L9_output.json

- **L1 only** (after attribution): Use sphere_rag.layers.layer_1.compute_L1(total_tokens, matched, F, A, eps) with sphere_rag.layers.load_defaults().

- **L1+L2**: python3 -m sphere_rag.layers.run_l1_l2 (writes to stdout or --out).
- **L1+L2+L3**: python3 -m sphere_rag.layers.run_l1_l2_l3.

- **Core math (v0.3)**: python sphere_rag/hesperia_v03_core_math.py [test].
- **Simulation**: python sphere_rag/run_simulation.py full|chroma|serve [options].
- **API**: python sphere_rag/serve_v033.py or run_simulation.py serve [port].

------------------------------------------------------------
What's expected
------------------------------------------------------------

- **Determinism**: Same inputs (attribution counts, topology, defaults) → same L1–L9 outputs. No LLM in layer math.
- **Output**: Full pass produces one JSON (all layer outputs) and can be summarized in a report (L7 DECISION_STATUS_CODE, OUTPUT_TRUST_TAG; L9 BRAND_WORD_*).
- **Stub run**: Without real retrieval (R_B/R_S empty), L4/L5 evidence metrics are zero; L9 may show FRAGILE/UNSUPPORTED — expected. With real Dict A/B and optional Chroma retrieval, values populate.
- **Logging**: Output log dir is docs/layer_runs/; overwrite latest_L1_L9_output.json each run. Keep copies if you need history.
