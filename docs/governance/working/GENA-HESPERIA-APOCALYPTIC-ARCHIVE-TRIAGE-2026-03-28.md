## 1. Goal

One recoverable **data root** (`/data/hesperia/`) that contains:

1. **Canonical Hesperia git working tree** — `hesperia/` (this repo).
2. **Existing cold backups** — `hesperia-backup/` (git mirror + tar snapshots + any corpus tarballs already there).
3. **Sister automation / workflow context** — read-only mirror of whatever lives at **`/data/workflows`** (or operator-provided path) into a **sibling directory** next to the repo, **not** inside git (large / non-Hesperia).

So recovery does not depend on remembering a second top-level mount.

## 3. Recommended layout under `/data/hesperia/`

```text
/data/hesperia/
  hesperia/                    # git clone (this repository)
  hesperia-backup/             # existing: git-mirror/, snapshots/, optional corpus tars
  workflows-mirror/            # NEW: rsync from WORKFLOWS_SRC (read-only, periodic)
  .vscode/                     # optional IDE shared config (low value for apocalypse)
```

- **`workflows-mirror/`** — not committed to Hesperia; regenerated by `tools/mirror_sister_workflows_into_hesperia_data.sh`.
- **Do not** git-commit the mirror; optional `sha256sum` manifest next to tar for integrity.
