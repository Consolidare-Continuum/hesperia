HESPERIA — Families Passes and Safety v0.1

Purpose:
Summarize the first explicit wiring between Areas at the Family level,
and define how geometry-preserving passes and safety-oriented control
stops interact in the engine math.

Relations:
- Builds on: 10_MASTER_SPEC__HESPERIA_v1_0.txt
- Uses ontology: 30_FAMILIES__HESPERIA_hex_canonical_v1_0.txt,
  31_FAMILIES__area_family_table_full.txt
- Uses indexing: 13_SPEC__Indexing_and_Coordinates_v1_0.txt
- Respects traversal policy: 40_POLICY__Loopability_and_traversal.txt,
  41_POLICY__Operational_additions_v0_1.txt
- Data files:
  - HESPERIA_FAMILIES_SETUP_V0.1.txt
  - HESPERIA_FAMILIES_PASSES_v0_3.csv
  - HESPERIA_FAMILIES_PASSES_control_stops_v0_1.csv
  - HESPERIA_FAMILIES_PASSES_matrix_v0_1.csv

============================================================
1. Layered Structure
============================================================

We introduce two distinct but compatible edge layers on top of the fixed
Area/Family geometry:

1. Geometry Passes (border edges)
   - File: HESPERIA_FAMILIES_PASSES_v0_3.csv
   - Meaning: neutral, geometry-aligned passes between neighboring Areas
     on the canonical ring, plus CONTROL ↔ DECEIT ↔ TRUTH regulatory
     links.
   - Use: loopability, traversal, and general semantic exploration.

2. Control Stops (safety edges)
   - File: HESPERIA_FAMILIES_PASSES_control_stops_v0_1.csv
   - Meaning: directed safety edges from high-risk families (HARM,
     DESTRUCTION, CHAOS, DECEIT) into stabilizing families (GOOD,
     TRUTH, FREEDOM, ORDER).
   - Use: policy overlays, risk-aware redirection, and safety brakes.

The underlying hex / ring geometry from 13_SPEC and
HESPERIA_FAMILIES_SETUP_V0.1.txt is not changed by these layers.

============================================================
2. Counts and Proportions
============================================================

Total families:
- 12 Areas × 24 Families per Area = 288 Families (global_id 0..287).

Geometry Passes (border layer):
- File: HESPERIA_FAMILIES_PASSES_v0_3.csv
- Passes: 52 directed border passes (including CONTROL–DECEIT–TRUTH).
- Distinct Families touched: 95.
- Proportion: 95 / 288 ≈ 0.33 (≈ one-third of Families participate in
  normal cross-Area borders).

Control Stops (safety layer):
- File: HESPERIA_FAMILIES_PASSES_control_stops_v0_1.csv
- Stop edges: safety redirects, focused on high-risk semantics.
- Distinct Families touched: 67.
- Proportion: 67 / 288 ≈ 0.23 (≈ one-fifth of Families participate in
  explicit safety brakes).

Union of external semantics:
- Definition: Families that appear in either passes or control stops.
- Distinct Families in union: 144.
- Proportion: 144 / 288 = 0.5.
- Interpretation: exactly half the Families have some external semantics
  (border and/or stop), half remain purely internal.

Purely internal Families:
- 288 − 144 = 144 Families.
- Proportion: 144 / 288 = 0.5.
- Interpretation: half of the lattice stays entirely local to its Area,
  with internal ring neighbors only.

These counts are deliberate: the lattice is split cleanly into
“externally engaged” vs. “purely internal”, while still keeping the
border (≈0.33) and safety (≈0.23) layers as overlapping sets rather than
probability buckets.

============================================================
3. Geometry Passes (v0.3)
============================================================

File: HESPERIA_FAMILIES_PASSES_v0_3.csv

Format (per row):
- border_name      : string (e.g., GOOD-CARE)
- border_slot      : 0..3 (four passes per border)
- from_area_id     : 0..11
- from_area_name   : GOOD, HARM, TRUTH, ...
- from_global_id   : 0..287
- from_family_name : canonical Family label from setup
- to_area_id       : 0..11
- to_area_name     : neighboring Area on the ring
- to_global_id     : 0..287
- to_family_name   : canonical Family label from setup
- notes            : short semantic rationale

Semantics:
- Passes follow the canonical ring order from the Families specs and
  13_SPEC: GOOD → CARE → ORDER → CONTROL → INDIFFERENCE → HARM →
  DESTRUCTION → CHAOS → FREEDOM → TRUTH → CREATION → GOOD.
- Each border has 4 passes (border_slot 0..3), chosen to be
  semantically plausible links between edge Families of the two Areas.
- Additional regulatory borders:
  - CONTROL ↔ DECEIT: control systems misused or resisting deceit.
  - DECEIT ↔ TRUTH: epistemic tension and correction paths.

Usage:
- Traversal engines treat these as neutral, geometry-consistent edges.
- Loopability metrics (40_POLICY) can count novel Families discovered
  via these passes without involving policy-specific safety behavior.

============================================================
4. Safety Control Stops (v0.1)
============================================================

File: HESPERIA_FAMILIES_PASSES_control_stops_v0_1.csv

Format (per row):
- control_name     : string (e.g., HARM-GOOD_CORE)
- from_area_id     : source Area id
- from_area_name   : source Area name
- from_global_id   : source Family global_id
- from_family_name : source Family label
- to_area_id       : destination Area id
- to_area_name     : destination Area name
- to_global_id     : destination Family global_id
- to_family_name   : destination Family label
- policy           : currently "STOP" for all entries
- notes            : human-readable safety rationale

Design:
- HARM → GOOD / CREATION:
  - Violence → Protection, Exploitation → Fairness, Harassment → Community,
    Vengeance → Researching, Coercion → Collaboration, etc.
- DESTRUCTION → TRUTH / FREEDOM:
  - Death → Evidence, Damage → Traceability, Erasure → Auditability,
    Invasion → Laws, Destroying → Exit, Devastation → Rights, etc.
- CHAOS → ORDER:
  - Turmoil → Standard, Instability → Protocol, Swarming → Response.
- DECEIT → TRUTH:
  - Lies → Clarity, Conspiracism → Consensus, Forgery → Traceability,
    Gaslighting → Testing, Clickbait → Verification, Subterfuge → Clarity.

Semantics:
- These edges are not new geometric borders; they are **policy overlays**
  that can be activated when the engine detects high-risk activation in
  HARM / DESTRUCTION / CHAOS / DECEIT.
- Engines can down-weight or redirect flows along these edges to move
  the system toward GOOD / TRUTH / FREEDOM / ORDER.

============================================================
5. Combined Matrix (v0.1)
============================================================

File: HESPERIA_FAMILIES_PASSES_matrix_v0_1.csv

Purpose:
Provide a single indexed matrix-like representation of both passes and
control stops, suitable for mathematical manipulation and embedding into
hex / side coordinates from 13_SPEC.

Format:
- edge_id       : PASS_xxx or STOP_xxx (unique per row)
- edge_group    : border_name (for passes) or control_name (for stops)
- edge_slot     : border_slot for passes (0..3); empty for stops
- from_global_id: Family global_id (0..287)
- from_area_id  : Area id (0..11)
- to_global_id  : Family global_id (0..287)
- to_area_id    : Area id (0..11)
- edge_type     : PASS or STOP
- weight        : numeric weight (1.0 for PASS, 0.2 for STOP, by
                  convention)

Notes:
- This is an adjacency list; hex and side coordinates follow from
  HESPERIA_FAMILIES_SETUP_V0.1.txt and 13_SPEC. For “truth hexes and
  segments”, engines may map these indices to geometric letters or
  segment IDs as needed.
- The weights are conventional and may be adapted (e.g., STOP edges
  treated as dampening factors, barriers, or high-penalty edges).

============================================================
6. Intended Engine Use
============================================================

Engine design expectations:

1. Geometry core stays fixed:
   - Areas, Families, and local ring neighbors come from the canonical
     specs and HESPERIA_FAMILIES_SETUP_V0.1.txt.

2. Passes drive exploration:
   - HESPERIA_FAMILIES_PASSES_v0_3.csv encodes neutral cross-Area
     motion used by loopability logic and traversal.

3. Stops enforce safety:
   - HESPERIA_FAMILIES_PASSES_control_stops_v0_1.csv defines safety
     redirects that can:
     - Break or slow harmful trajectories.
     - Prefer GOOD / TRUTH / FREEDOM / ORDER when risk is high.

4. Clean partition for math:
   - Exactly half the Families (144 / 288) have some external semantics
     (border and/or stop).
   - The other half are internal-only, preserving strong local meaning.

This layered construction is intended to support both mathematical
clarity (clean counts, fixed geometry) and safety-aware behavior
consistent with HESPERIA’s policy goals.
