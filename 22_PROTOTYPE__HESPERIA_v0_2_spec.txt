0. Purpose
The HESPERIA hex-sphere geometry is a closed-loop semantic lattice:
12 Areas × 24 Families × 72,000 hexes × 432,000 atomic truth sides.
This spec defines the math apparatus for capacity, truth, structure, dynamics, and composite scores in Java-style expressions, with short descriptions for each term.

1. Core Ontology

1.1 Areas and Ring Order
AREAS
final int AREAS = 12;
Number of semantic macro-Areas. All Area-indexed arrays have length 12.

Area list (antipodal pairs)
GOOD ↔ HARM
TRUTH ↔ DECEIT
ORDER ↔ CHAOS
FREEDOM ↔ CONTROL
CARE ↔ INDIFFERENCE
CREATION ↔ DESTRUCTION

Ring order (C₁₂ loop)
GOOD → CARE → ORDER → CONTROL → INDIFFERENCE → HARM →
DESTRUCTION → CHAOS → FREEDOM → TRUTH → CREATION → GOOD

1.2 Families
FAMILIES_PER_AREA
final int FAMILIES_PER_AREA = 24;

TOTAL_FAMILIES
final int TOTAL_FAMILIES = AREAS * FAMILIES_PER_AREA; // 288

3. Truth Model and Content Capacity

3.1 Truth per Side
double tau[]; // 0.0 <= tau[s] <= 1.0

final double TAU_THRESHOLD = 0.8;

3.2 Filling and Capacity
countSides(R)
filledSides(R)
fillingRate(R) = filledSides(R)/countSides(R)

3.3 Sentence Capacity
minSentences(R) = filledSides(R)*3
maxSentences(R) = filledSides(R)*5
avgSentences(R) = filledSides(R)*4

3.4 Truth Magnitude and Density
T(R) = Σ tau[s]
T_max(R) = countSides(R)
T_norm(R) = T(R)/T_max(R)
truthPoints(R): tau[s]>=0.8
truthPointDensity = truthPoints/countSides

4. Graph Structure and Clusters
Adjacency matrix A[i][j]

K(R): connected components
L(R): largest component

C(R)=L/active
fragIndex(R)=K/active

adjacencyCorrelation(R)=1 - mean(|tau[i]-tau[j]|)
